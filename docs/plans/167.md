# Plan for #167: does the M7 need a PERF_M7 API line (system-manager-config)

Status: provisional. Survey only; no `.cfg` patch is proposed here. The #13
delta is still pending owner approval.

## Objective

M7 agent needs a `PERF_M7` (performance domain) API line in the board
configuration to set its own clock or performance level, and what it can do
without one. Every claim cites an imx-sm file and line at the pinned revision.
