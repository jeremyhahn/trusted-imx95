# Plan: #160, first full Yocto build of the provisional platform image

Provisional: the BSP baseline is the owner's to choose (#14). No flash, no
board, no key, no fuse; the ftpm configuration (#140) is not part of this lane.

## Objective

Build `trusted-imx95-image` (and the debug image with `PI_DEBUG=1`) from the
pinned layers on a lane host, record what the build does, and fix the
configuration errors it reveals in `platform-image/`, never by unpinning a
layer.

## Slices, in order

1. Build entry point: `make platform-image` runs `scripts/platform-image-build.sh`.
   It fetches the pins (platform-image-fetch), sets up the build directory
   outside the clone, names every missing host tool, runs bitbake, and writes
   the artefacts, `SHA256SUMS` and `build-info.txt` (layer revisions, MACHINE,
   DISTRO, SOURCE_DATE_EPOCH) to the git-ignored `.platform-image/out/`.
   `--check` (alias `--dry-run`) builds nothing.
   Test: `test/platform_image_build_test.sh` (stub bitbake and fetcher, run by
   `make test`).
2. The build: run in the background, log outside the clone, fix configuration
   errors in `platform-image/`. If the host cannot run it, `build.md` names the
   precise blocker and the furthest task reached.
3. Docs: `docs/platform-image/build.md` records the command, artefacts, digests
   if built, time and resources, and every gap (provisional).

4. Layer check: `scripts/platform-image-layer-check.sh` (`make platform-image-layer-check`)
   checks the BBLAYERS layers' `conf/layer.conf`, `LAYERDEPENDS` and
   `LAYERSERIES_COMPAT` on a fetched tree, as text, no bitbake. Test:
   `test/platform_image_layer_check_test.sh` (stub tree, in `make test`).
5. eMMC layout: `docs/platform-image/emmc-layout.md` (proposed, pending owner
   approval), checked by `test/platform_image_docs_test.sh`. The user-area wic
   layout is #140's (PR #158), cited, not copied.
6. Output check: `scripts/platform-image-verify.sh` (`make platform-image-verify
   OUT=...`) checks an output directory against `manifest.lock`, offline. Test:
   `test/platform_image_verify_test.sh`.
7. Production manifest: verify fails when `trusted-imx95-image`'s `.manifest`
   holds a package the debug recipe adds; `build.md` gets an ordered "Operator
   procedure" for the run after the owner accepts the EULA. 160-pi-s5: the same
   check refuses a package manager (`rpm opkg dnf apt dpkg`) in that manifest.

## Out of scope

AHAB signing, flashing, dm-verity, ftpm, accepting NXP's EULA (the owner's, #14),
CI for the build.
