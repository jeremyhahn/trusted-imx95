# Plan 163: SRK hash check of a public SRK set

## Objective
`make srk-hash-check`: with the pinned SPSDK, compute the SRK table hash of four public SRK
keys or certificates and compare it with an expected value from a file. Host-side only.

## Slices
1. The check: `scripts/ahab/srk-hash-check.sh`, `scripts/ahab/srk-hash.py`, the Makefile
   target. Refuses private keys, non-PEM input, a count other than four, a bad expected file.
   Test: `test/srk_hash_check_test.sh` (match, mismatch, wrong count, private key refused,
   test PKI generated per run outside the tree).
2. Docs: `docs/oem-key-provisioning/srk-hash-check.md` (provisional), linked from
   `architecture.md`.

## Out of scope
Programming the hash, any fuse, life-cycle, RPMB or board step; the fuse word layout.
