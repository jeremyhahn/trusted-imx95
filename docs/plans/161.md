# Plan: #161 the test-PKI signed boot container set, no flash

Objective: `make ahab-boot-image-test` builds and signs, with the pinned SPSDK on a
throwaway test PKI, every boot container buildable from open sources, and verifies
each. The EULA-gated pieces are recorded as gaps, not fetched. Nothing is flashed.

## Slices

1. The container set.
   - scripts/ahab/boot-image-test.sh with boot-image-m33.yaml (System Manager from
     `make system-manager`, synthetic M7) and boot-image-a55.yaml (BL31 and OP-TEE
     from `make secure-world`, synthetic U-Boot). Test keys in a mktemp directory
     outside the clone, deleted on exit.
   - Makefile `ahab-boot-image-test`; builds the inputs only when absent.
   - test/ahab_boot_image_test.sh: each container verifies; a flipped byte in any
     image entry fails; no key file left; the clone is unchanged.
2. Record and gaps: docs/boot-container/boot-image.md, linked from architecture.md.

## Gaps (each names what it waits on)

- EdgeLock firmware container, OEI image, DDR firmware: NXP EULA, the owner.
- U-Boot and SPL: the BSP baseline #14 (u-boot-imx pin), then a build.
- A flashable image: an owner decision; not made.
- Real keys in HSM custody: AN14471, blocked.
- Container version, fuse_version, entry rule: IMX95RM and the Security RM.

## Out of scope

Keys, fuses, life cycle, RPMB, any board step, the CST, the NXP EULA, flashing.
