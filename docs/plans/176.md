# Plan 176: the life cycle closes only at the provisioning station

Branch `row/176-okp-lc-station`. Epic row: `oem-key-provisioning`. Refs #176.

## Objective

Owner ruling 1234 (Tenant, 2026-11-23): the device life cycle is closed only at the
provisioning station, never on a development board. This answers two open questions of the
row (when the life cycle closes, where provisioning runs). The row stays blocked on the
missing IMX95RM and Security Reference Manual. The repository must never run a close.

## Slices

1. State the ruling.
   - docs/SPEC.md (oem-key-provisioning row only), ROADMAP.md (oem-key-provisioning entry
     only) and docs/oem-key-provisioning/architecture.md say it, citing ruling 1234.
   - The two open questions are removed. architecture.md also says RPMB key programming for
     the ftpm row follows OEM close at that station.
   - Check: the diff of SPEC.md and ROADMAP.md touches only that row and entry.
2. A guard that the repository never closes the life cycle.
   - test/no_lifecycle_close_test.sh (picked up by `make test` through the test/*_test.sh
     glob) fails when a script, make target or workflow runs an OEM-close or life-cycle
     command: SPSDK life-cycle or close operations, the enclave's forward-life-cycle
     message, a fuse write.
   - Fixtures that only name the message (the ahab key-import and key-exchange tests) are in
     an allow-list by path, each with a reason.
   - The test checks itself: a scratch copy of a script with a close command added must make
     the scan fail and name the file.

## Out of scope

- Any fuse burn, life-cycle change, RPMB key programming, board, flash or block-device step.
- The IMX95RM and Security Reference Manual facts (missing); SPSDK-or-other-path and
  HSM-API-side questions stay open.
- Vendor (NXP) code or text: cited only.

  life-cycle guard's allow-list because it holds the tool names it rejects.
- Scratch check: with the old prefix in a copy, the `if fastboot flash` fixture is not flagged;
  restore with `git checkout test/okp_host_only_test.sh`.
